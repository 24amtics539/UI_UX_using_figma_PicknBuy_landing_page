# PicknBuy — Luxury Furniture E-Commerce Landing Page Design in Figma

## Project Overview
PicknBuy is a luxury furniture e-commerce landing page designed in Figma. It introduces a curated studio platform that helps users discover thoughtfully crafted furniture for mindful living, slower mornings, and warm interior spaces.

## Objective
To create a visually appealing, responsive luxury product landing page using Figma Auto Layout, reusable components, and consistent UI/UX design principles.

## Target Audience
- Design-conscious homeowners investing in long-term, curated living spaces
- Urban professionals seeking mindful, slow-furniture alternatives to mass-produced items
- Interior designers and residential decorators sourcing hero and accent furniture
- Shoppers looking for transparent pricing, honest materiality, and lasting craftsmanship

## Main Features
- Header with brand wordmark, navigation links (Shop, Collections, Our Story, Journal), and mobile menu toggle
- Hero section with living room photography, lifestyle headline ("Spaces that feel like you"), and a "Shop the collection" call-to-action button
- Curated collection grid with category badges, serif titles, and illustrative Indian pricing:
  - The Haven Sofa (Lounge) — ₹48,900
  - Arlo Lounge Chair (Living) — ₹22,500
  - Forma Dining Table (Dining) — ₹36,000
  - Sora Floor Lamp (Lighting) — ₹8,900
- Three feature cards covering "The PicknBuy Difference":
  - Thoughtful by design (balanced proportions and natural materials)
  - Built to belong (durable finishes for real living)
  - A smoother experience (transparent pricing and dependable delivery)
- Brand philosophy and narrative section ("Less, but more meaningful")
- Newsletter subscription section ("Make room for inspiration")
- Comprehensive footer with categorized links (Explore, Help, Follow Along) and copyright notes
- Responsive desktop (1440px) and mobile (390px) layouts

## Design System
- **Primary accent:** Champagne gold — #C2965E
- **Dark background:** Ink — #0E100F
- **Card background:** Surface / dark charcoal — #171A17 / #212420
- **Earthy accent:** Olive — #4A5844
- **Primary text:** Warm ivory — #F5F0E0
- **Secondary text:** Muted stone — #ABAB9C
- **Typography:** Playfair Display for editorial headlines and titles; Inter for body copy, category badges, and pricing

## Reusable Components
- Header with navigation links and mobile drawer trigger
- Reusable product card with image container, category badge, product title, and price
- Reusable feature card with icon, title, and supporting description
- Primary call-to-action button with editable label
- Responsive footer component with link columns

## UI/UX Concepts
- Figma Auto Layout for sections, headers, grids, cards, and buttons
- Reusable local components and variant styles
- Shared color and typography styles
- Clear visual hierarchy, balanced proportions, and generous whitespace
- Responsive desktop (1440px) and mobile (390px) compositions
- Indian currency formatting (INR — ₹) with clear, transparent pricing

## Design Choices
The dark ink palette and warm living room photography create an intimate, gallery-inspired luxury identity. Champagne gold accents highlight primary actions and prices without visual clutter, while editorial serif typography paired with clean sans-serif body text reinforces artisanal heritage and high legibility.

## Tools Used
- Figma
- Figma Auto Layout
- Figma Components
- Figma Color and Text Styles
